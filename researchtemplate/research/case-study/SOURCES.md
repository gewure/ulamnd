# Sources for the process record

Every claim the record makes, and where the evidence for it is. Same rule as everywhere else: a statement
without a source is not written.

| claim | where the evidence is |
|---|---|
| timeline, commits per day | `git log`; regenerated by `scripts/process-record.py` |
| what was tested and what it showed | `research/experiments/REPORT.md`, `CONCLUSIONS.md` |
| the state at any date | `research/KNOWLEDGE.md` §1 (timeline), §0b (state) |
| the guardrails and when each entered | `METHOD.md`; `KNOWLEDGE.md` §0b, §3; `ERRATA.md` |
| the error record | `KNOWLEDGE.md` §3 (F-numbers), `ERRATA.md` (dated items) |
| outside readings and their findings | `research/reviews/` (with revision hashes), `KNOWLEDGE.md` §0c |
| findings that were rejected, and why | `ERRATA.md` |
| what the human did and decided | `INTERVIEW.md`, verbatim answers |
| the human's prompts | session transcripts (not in the repository unless you put them there) |
| page counts, document sizes | `pdfinfo` on the compiled PDFs, via `scripts/process-record.py` |
| cost | {{your own record of tokens and compute}} |
